# Smart Notch for Windows

![Smart Notch](icon.png)

A Dynamic Island–style notch for Windows: music with synced lyrics, system stats, Bluetooth, focus timer and quick controls at the top of your screen, plus Notchy, a companion that follows your AI coding agents.

[Get Smart Notch from Microsoft Store](https://apps.microsoft.com/detail/9N1D46F5X565) · [Website](https://smart-notch-windows.vercel.app/) · [Report a problem](https://github.com/Avenger11764/Smart-notch/issues/new/choose) · [Release notes](CHANGELOG.md)

This is the public product and support repository. The application source is maintained privately. You don't need GitHub or developer tools to install the app.

**Latest: 7.2.0** brings Notchy following your AI agents on its own (Pro), one System stats view you can customise, better support for desktop PCs, a redesigned Focus timer with drag-to-reorder tasks, smoother lyrics and a camera-indicator fix. See [CHANGELOG.md](CHANGELOG.md) for details.

## What it does

- **Three styles:** an edge notch, a floating pill or a full-width bar, on the top or either side of any display.
- **Music:** artwork, controls, audio output switching and synced lyrics for Spotify, browsers and other media apps, plus a fullscreen listening room with visualizers.
- **System stats:** CPU, memory, network, storage, battery and uptime in one view. Pick which tiles you want, and what the closed notch shows (battery on laptops, CPU or memory on desktops).
- **Everyday controls:** volume, brightness, Bluetooth devices, weather, and shortcuts to Calculator, Snipping Tool and Task Manager.
- **Focus timer:** work and break sessions with a task list you can reorder by dragging and sort.
- **Privacy indicators:** green and orange dots while an app uses your camera or microphone.

## Free and Pro

Everything above is free. Smart Notch Pro is a one-time upgrade through Microsoft Store that adds:

- **Notchy:** follows Claude Code, Codex and Antigravity as they work, shows each step and file change, lets you answer questions and permission requests from the notch, and includes account usage and a detachable desktop screen.
- **Edge Light:** a bright band around your screen to light your face on video calls.
- **Drop Shelf, Clipboard history** (pins, images, smart actions), **Download progress** and the **Volume Mixer**.
- **Quick Apps**, the **Invisibility Cloak** privacy blur, fullscreen music extras and custom notch size and placement.

Agent features depend on the agent tools being installed and signed in; usage figures come from each provider.

## Get help

First update through Microsoft Store → Library, and see [TROUBLESHOOTING.md](TROUBLESHOOTING.md). If the problem remains, use **Settings → About → Report a problem** in the app, or [open a bug report](https://github.com/Avenger11764/Smart-notch/issues/new/choose) with your app version, Windows version, notch/pill/bar style, Free or Pro, and the steps to reproduce.

Crop screenshots and remove account details. Never post passwords, tokens, private clipboard contents, payment information or full unreviewed logs.

Feature ideas are welcome through the issue templates. This repository accepts documentation and support contributions, not application source changes.

## Updates

Install and update through Microsoft Store. [CHANGELOG.md](CHANGELOG.md) marks which versions are released and which are still being certified. The `update.json` file tells the app when a newer version is live; it contains no application source. If an older copy still says it is up to date, open the Store listing and check for updates there.

## Privacy

Smart Notch runs on your PC and needs no account. Some features go online, such as lyrics, weather and update checks. Read the [Privacy Policy](PRIVACY.md) for details on local storage, online features and your controls.
